# 22.1의 5번 — 인력 유형/전체 보기·전용 엑셀

2026-10-13, PRD 5.7/인력/엑셀 정책, P3.2 0.1~0.5 및 22.1 5번, P2 4.6/4.9/12.3, P3.3 후보 규칙을 적용했다. 신규 의존성·DB 스키마 변경은 없다.

## 구현

- 인력 관리: 전체/PMO/영업/기술/외부 보기, 유형 열·등록/수정 선택, 유형별 필수값 표시/검증. 소속/팀/직위는 기존 후보를 참고하면서 새 원본값도 입력할 수 있다. 영업 유형은 비활성 인력을 포함하고 후보 API는 기존 활성 조건을 유지한다.
- 엑셀: 원본 사번·내부 UUID·명시 유형·역할 코드 포함 동일 양식 다운로드/템플릿. 검증만으로 DB를 변경하지 않고 신규/수정/동일/오류·필드별 차이·범위 내 누락을 보여준다. 기존은 ID로만 수정, 신규 ID는 서버 발급, 미존재/중복 ID 및 중복 식별값 차단. ID 없는 구형 인력 파일은 새 템플릿으로 전환해야 하며 기존 통합 업로드 제거는 8번이다.
- 선택 유형별 파일은 해당 유형만 누락 비교한다. 다른 유형 누락 비활성화 요청은 서버에서 차단한다. 전체/유형별 모두 기본 유지, 개별/일괄 비활성화, 인력 물리 삭제 없음.
- 엑셀 실행은 DB 기반 personnel_excel_manage, 일반 등록/수정과 본부장 상태 변경 예외는 기존 권한으로 분리한다. 명시 PMO 유형 CRUD/새 엑셀 필수값 적용, 구형 유형 누락 등록/PATCH의 전환/저장값 유지 계약 보존.
- 사용자·30분 메모리 토큰·동일 해시·인력/역할/공휴일/업무 원장 변경 재확인. 자동 통합 JSON 백업→공통 JobLock/SQLite 쓰기 잠금→트랜잭션 반영, 실패 전체 롤백/잠금 해제. 성공/실패 작업 이력과 업로드 전 백업을 기록한다.
- 기존 생성기에서 인력별 스냅샷 함수를 추출해 재사용했고 프로젝트/인력의 미리보기·누락 선택 UI/다운로드·DB fingerprint를 공통화했다.

## 파생 데이터 경계

- 연간 재직 MM은 현재 연도 12개월의 기존 근무일/재직기간 산식으로 서버가 표시 계산한다. 엑셀의 연간 MM/역할 표시명 입력은 무시한다. PMO 외 인력은 MM/KPI 합계에 포함하지 않는다.
- 유형·MM 기간·재직/활성 상태가 변한 인력만 현재 연도 당월~12월의 재직 MM과 당월 이후 KPI를 갱신한다. 기본정보/비고만 바뀌면 수동 MM 보정을 유지한다. 기존 가동률/가득률 산식은 변경하지 않았다.
- 오늘 스냅샷은 기존 ID·운영 메모·monthly_mm를 보존하면서 갱신한다. 현재 비PMO/비활성은 오늘 PMO 스냅샷에서 제외한다. 과거 MM·스냅샷·KPI는 덮어쓰지 않는다.
- 프로젝트·배정·투입 MM·진행이력과 UUID/FK 참조는 유지한다. 프로젝트에 저장된 PM/영업 성명 문자열 자동 치환이나 배정 CRUD는 이번에 구현하지 않았다.

## 남은 확인 및 다음 시작점

- 사용자 브라우저: 인력 관리 유형 필터/등록 선택/필수 표시, 신규 소속·팀·직위 입력, 권한 있는 계정의 다운로드/업로드 버튼, ID 포함 파일 검증·누락 기본 유지·일괄 선택. 검증 후 닫으면 DB는 변경되지 않는다.
- 최종 읽기 전용 포트 점검에서 웹 3000은 실행 중이고 API 8001은 리스닝하지 않았다. 브라우저 확인 전 사용자 터미널에서 npm run dev:api를 다시 실행해야 한다. 검증을 위해 사용자 서버를 종료하거나 새 검증 서버를 남기지 않았다.
- 신규 업로드 후 ID 포함 파일을 재다운로드해 다음 수정에 사용한다. 같은 ID 없는 신규 파일을 재업로드하면 기존 식별 후보/사번/이메일 충돌을 오류로 표시한다.
- 백업은 기존 통합 JSON 형식과 구형 유형 없는 JSON 복원 규칙을 재사용한다. 실제 반영 뒤 복구가 필요하면 백업 화면에서 인력 업로드 전 백업을 선택한다. 통합 복원은 전체 업무 세트를 당시 상태로 돌린다는 기존 정책을 따른다.
- 과거 데이터의 소급 보정, 다음 연도 MM 생성, 로그인/운영 인증·권한 관리 화면, 여러 worker 공유 검증 캐시 및 PostgreSQL 통합 검증은 별도 작업이다. 현재 토큰은 서버 재시작 후 다시 검증해야 한다.
